# Page Pulse

## Project Overview
Page Pulse is a web application that analyzes any website URL and displays useful information about the webpage.

## Features
- HTTP Status
- Response Time
- Page Title
- Meta Description
- H1 Count
- Images Without Alt Text
- Approximate Word Count

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Axios
- Cheerio

## Installation

1. Install dependencies

```
npm install
```

2. Start the server

```
node server.js
```

3. Open index.html using Live Server.
